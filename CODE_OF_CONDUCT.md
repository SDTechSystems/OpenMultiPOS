# Convivencia

Colaborar con respeto. Se aceptan preguntas y desacuerdos técnicos argumentados. No se permiten acoso, discriminación, exposición de datos privados o ataques personales. Reportar problemas al mantenedor a través de los canales disponibles de GitHub; no publicar datos de terceros. El mantenedor puede moderar contenido o participación para proteger a la comunidad.
