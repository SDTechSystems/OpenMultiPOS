# Recursos de OpenMultiPOS

Este directorio contiene los estilos, scripts y recursos de interfaz que Bench publica para la aplicación OpenMultiPOS. Incluye el espacio administrativo, la caja, la vista previa de recibos y las ayudas de cada sección.

La configuración y el proceso de compilación se describen en la [guía de desarrollo](../../docs/development.md).
